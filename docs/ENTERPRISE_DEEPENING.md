# IAM 企业深化说明

> 上海如静知华信息科技有限公司 · [知华科技官网](https://www.zhuatech.cn/)

本轮新增真实持久化的租户、身份、角色、访问申请、授权关系与审计事件模型，形成“租户启用 → 身份建档 → 角色定义 → 访问申请 → 管理审批 → 授权回收/到期失效”的完整链路。

关键控制包括：特权角色必须启用 MFA；付款制单/付款审批、用户管理/审计复核采用职责分离门禁；身份与角色必须属于同一租户；普通操作员不可调用管理接口；核心聚合使用乐观锁字段防止并发覆盖。

验收覆盖正常授权、特权 MFA 拦截和管理接口越权拒绝。该版本是企业二次开发基线；生产部署还应接入企业目录、密钥托管、真实 MFA、审批组织架构、监控告警和灾备体系。
